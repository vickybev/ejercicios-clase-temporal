# Ejercicios de clase - Programación 2

Repositorio para organizar los ejercicios realizados durante el semestre.

## Estructura

Cada clase tiene su propia carpeta. Dentro de ella se guarda un archivo `.py` por ejercicio y se realiza un commit descriptivo por cada uno.

```text
ejercicios-clase/
├── clase-02/
├── clase-03/
└── ...
```

## Flujo de trabajo

1. Hacer `pull` antes de comenzar.
2. Crear o modificar el ejercicio.
3. Hacer un commit con un mensaje que explique el cambio.
4. Hacer `push` para enviarlo a GitHub.
